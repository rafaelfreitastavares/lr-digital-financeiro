Conexão configurada — testes pendentes Banco de dados Supabase

Este aplicativo tenta autenticar o usuário e ler/gravar dados da equipe no Supabase. A sincronização só deve ser considerada validada depois de testar login, inclusão, edição, exclusão e acesso por um segundo usuário autorizado.

  1. Entre com a conta criada em Authentication → Users.
  2. Confira se clientes, lançamentos, compras parceladas e fechamentos são carregados do banco.
  3. Crie um registro de teste, atualize a página e confirme que ele continua presente.
  4. Repita o teste em outro navegador/dispositivo com um segundo usuário adicionado à equipe.

Segurança: somente a Publishable Key está no código do navegador. Nunca coloque service_role ou secret key no HTML.

Checklist de testes antes de usar:

  • Login e logout funcionam.
  • Usuários autorizados da mesma equipe enxergam os registros compartilhados.
  • Dados criados no computador aparecem no celular depois de entrar na mesma conta.
  • Editar/excluir funciona sem duplicar dados.
  • Backup e restauração foram testados.
  • Teste com dados fictícios antes de migrar dados reais.

Estado atual desta versão

O código inclui login Supabase e operações de leitura/gravação para a equipe. A conexão ainda não foi testada no seu ambiente publicado; valide com dados fictícios antes de usar registros reais.

Não informe dados bancários completos, senhas ou informações de cartão sensíveis neste protótipo.
